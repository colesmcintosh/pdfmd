# pdfmd v0.4.0
GitHub crates.io Releases

PDF bytes in. Markdown out.

Zero-dependency PDF → Markdown converter in Rust. Recovers columns, GFM tables, headings, and lists straight from glyph positions.

4.4 ms 17-page paper 0 dependencies ~700 KB binary 99% coverage
